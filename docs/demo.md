# Suggested demo sequence

1. Run `inventorypulse run`; open the local dashboard. Explain the fixed synthetic cutoff and illustrative USD.
2. Show source fingerprints and the four hand-offs under Agent evidence.
3. Open Quality & reconciliation: identify invalid prices, quantities, stale/future feeds and unmatched descriptions. Show matching scorecard and identical-cutoff reconciliation.
4. Open Inventory risk: PART-001 has 230 units, target 70 and 160 excess units at $15, giving $2,400 exposure. Every sixth SKU is obsolete, without double counting excess.
5. Open Recommendations: compare mutually exclusive options for PART-002 and inspect rates, handling costs, constraints and expected net recovery.
6. Enter the locally generated approval key, reviewer and rationale. Approve one option. Show updated approved opportunity, alternatives marked not selected and realized cash still zero. A repeated decision is rejected.
7. Show weekly audience-specific reports and exported breach events. Distinguish these from live Teams and Activator notifications.
8. In the actual Microsoft tenant, separately demonstrate notebook output tables, published Data Agent MCP call, four cloud agents, governed identities, Power BI, Activator and Teams. These steps are pending tenant access; do not imply the local demo performed them.
